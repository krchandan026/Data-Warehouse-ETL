# End-to-End Data Warehouse & ETL Pipeline

## Overview
This project demonstrates a real-world Data Engineering workflow.
It covers data ingestion, cleaning, transformation, and analytical reporting
using SQL and Python.

## Business Problem
A company wants to analyze sales performance, customer behavior,
and revenue trends using structured data.

## Tech Stack
- SQL
- Python
- SQLite
- Pandas

## Architecture
Raw CSV Data → Python ETL → Data Warehouse → SQL Analytics

## Project Structure
- data/        : Raw input files
- sql/         : Schema and analytics queries
- scripts/     : ETL pipeline
- README.md    : Project documentation

## Key Features
- Cleaned and validated raw data
- Designed a star-like schema
- Built an ETL pipeline using Python
- Generated business insights using SQL

## Insights Generated
- Total revenue
- Top-selling products
- Customer purchase behavior
- Daily sales trends
